# Test support

Import from `test/support/index.ts`.

## Fake Kubernetes API

```ts
import { startFakeApi, loadFixtureSet, scenarios } from "../support/index.js";

const api = await startFakeApi({ fixtures: loadFixtureSet("synthetic") });
const config = api.kubeConfig(); // or api.writeKubeconfig() for a file
// ...
await api.close();
```

Read-only HTTP server over a fixture set: discovery, list, get, watch (with `resourceVersion`
replay), label and field selectors, pod logs, kubelet stats via `nodes/<n>/proxy/stats/summary`,
`SelfSubjectAccessReview`. Anything else that writes answers 405. Options: `absentGroups` (CRD
not installed: 404, gone from discovery), `forbidden` (403), `denied` (access reviews), `token`.
Mutate with `upsert`/`remove` (watch events follow); `dropWatches()` and `expireWatchHistory()`
exercise reconnect and relist.

client-node 2.x refuses plain http unless TLS verification is skipped, so the generated
kubeconfig sets `insecure-skip-tls-verify`.

## Fixture sets

`test/fixtures/<name>/` in the layout `scripts/capture-fixtures.sh` writes. `synthetic` is
generated by `test/support/k8s/synthetic.ts` (`node --import tsx test/support/k8s/writeSynthetic.ts`
regenerates it; a test fails when it is stale). To use a real capture, extract the archive to
`test/fixtures/real/` and run with `FIXTURE_SET=real`; tests that name scenarios (`scenarios.*`)
stay on `synthetic`.

## Fake SSH host

`startFakeSshHost({ password | publicKey, commands })` answers exec requests from a table (or
function), records `executed` and `unexpected` commands, exposes the host key fingerprint.

## kind

`test/support/kind/kind.sh up [set]` / `down`: kind cluster with CRDs and custom objects from a set.
